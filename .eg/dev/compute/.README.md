### compute daemon development workload

builds the eg daemon from source and runs it against the egmeta development services on the container host (`host.containers.internal`). start `dev/daemon` in egmeta first, it creates the account (`egci-meta accounts create`) and links the login key derived from `EG_DEV_SEED` to it. `EG_ACCOUNT` and `EG_DEV_SEED` default to the same values in both workloads, set them in both places to change them.

```bash
eg compute serve --ttl infinity dev/compute
```
