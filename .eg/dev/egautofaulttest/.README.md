### generate failing golang tests reproducing recent honeybadger errors using Claude

Reads the recent unresolved faults of the honeybadger project, then asks Claude (Sonnet 5.5) to write a test reproducing each fault in the function its stacktrace points at inside this repository.

If a test was generated it is committed and pushed to a new `egfault/tests-<short hash>-<fault id>` branch; nothing happens when no fault could be reproduced.

Requires `ANTHROPIC_API_KEY`, `HONEYBADGER_AUTH_TOKEN` (a personal auth token), and `HONEYBADGER_PROJECT_ID` in the environment; no local GPU is needed.

```bash
eg compute local --secret gcpsm://egd-esuite/egd-faultgen dev/egautofaulttest
```
