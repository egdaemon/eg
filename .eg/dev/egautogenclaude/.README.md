### generate missing golang tests using Claude

Runs the existing tests, records coverage, then asks Claude (Sonnet 5.5) to generate tests for the least covered functions.

If tests were generated they are committed and pushed to a new `egautogen/tests-<short hash>` branch; nothing happens when the workspace has no changes.

Requires `ANTHROPIC_API_KEY` in the environment; no local GPU is needed.

```bash
eg compute local --secret gcpsm://egd-esuite/egd-codegen dev/egautogenclaude
```
