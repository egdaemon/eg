### release command.

eg compute local --gcp-auto --secret gcpsm://egd-esuite/release-env release/eg/apt

builds and publishes the signed apt repository. the debs stay on the github releases, only the index
(dists/, InRelease, Release.gpg and key.asc) is generated and force pushed to the gh-pages branch. every
package in Packages points at its github release download url. all published releases are included
(amd64 only), run it after release/eg/automatic has promoted the release.

requires GitHub Pages to be enabled for the gh-pages branch (one time, in the repository settings), and
the EG_GPG_KEYRING_SEED, EG_GPG_KEYRING_NAME and EG_GPG_KEYRING_EMAIL environment variables, provided by
the release-env secret. the key is derived from the seed, so its fingerprint is stable across runs.

### usage

```bash
curl -fsSL https://egdaemon.github.io/eg/key.asc | sudo tee /etc/apt/keyrings/eg.asc
echo "deb [signed-by=/etc/apt/keyrings/eg.asc arch=amd64] https://egdaemon.github.io/eg stable main" | sudo tee /etc/apt/sources.list.d/eg.list
sudo apt update && sudo apt install eg
```
