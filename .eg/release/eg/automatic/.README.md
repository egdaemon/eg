### release command.

builds the tar.gz (amd64, arm64), pacman and deb artifacts in parallel. nothing is published by default.

- `--draft` creates the draft github release and has each build upload to it.
- `--release` (requires `--draft`) additionally promotes the github release.

eg compute local --gcp-auto --secret gcpsm://egd-esuite/ssh release/eg/automatic

eg compute local --draft --release --gcp-auto --secret gcpsm://egd-esuite/ssh release/eg/automatic
