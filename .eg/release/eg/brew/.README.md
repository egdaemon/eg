# homebrew formula

builds the keg and renders the formula into the workspace `.dist` directory. `--draft` uploads both to the draft github release.
`--release` (requires `--draft`) additionally pushes the formula to the tap, which only works once the github release is published.

```bash
eg compute baremetal --no-podman release/eg/brew
eg compute baremetal --no-podman --draft release/eg/brew
eg compute baremetal --no-podman --draft --release release/eg/brew
```
