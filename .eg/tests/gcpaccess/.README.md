### gcp access test.

verifies a runner's environment has working gcp application default credentials issued through the egd-workloads identity (workload identity federation), with no user setup.
no token or secret is printed, only whether a token could be minted.

prerequisites:
- the account has a connected gcp identity whose WIF pool trusts `egd-workloads@egd-workloads.iam.gserviceaccount.com`.
- the esuite daemon has `EG_COMPUTE_GCP_WORKLOAD_IDENTITY` set, or relies on its default of the above.

```bash
eg compute local tests/gcpaccess
```

expected output: `gcp access ok`. a failure on the `GOOGLE_APPLICATION_CREDENTIALS` check means the credentials never reached the runner environment.
