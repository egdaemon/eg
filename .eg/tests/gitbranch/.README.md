### gitbranch test.

verifies `eggit.Change`, `eggit.Commit` and `eggit.Push` on the host and within a container.

- clone enabled (`eg compute upload`, baremetal): dirties a change worktree, commits and pushes an `egtest/gitbranch-<environment>-*` branch, verifies it exists on the remote with `git ls-remote`, then deletes it. pushes a real branch, so it needs a token (or ssh access) with push rights to the head remote.
- clone disabled (`eg compute local`): nothing is pushed, verifies the patch written to the workspace directory (`.eg/.patches/{md5(branch)}.patch`, md5 formatted as a uuid, a `git am` compatible patch of the commits) is non-empty.

```bash
eg compute local tests/gitbranch
eg compute upload tests/gitbranch
```

expected output in the workload's logs: `gitbranch host successful` and `gitbranch container successful`.
