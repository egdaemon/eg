### gitclone test.

verifies cloning end to end, guest and host, including the destination of eggit.Clone.

- clone enabled (`eg compute upload`, baremetal): AutoClone clones into the working directory, the working directory is verified to be at the commit. eggit.Clone then clones the same commit into a directory of the cache which is verified as well.
- clone disabled (`eg compute local`): the clone is skipped and so is the verification.

```bash
eg compute local tests/gitclone
eg compute upload tests/gitclone
```
