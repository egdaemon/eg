### gitclone test.

verifies cloning end to end, guest and host.

- clone enabled (`eg compute upload`, baremetal): AutoClone clones into the working directory, the working directory is verified to be at the commit.
- clone disabled (`eg compute local`): the clone is skipped and so is the verification.

cloning into other directories (eggit.Clone, eggit.CloneOp) is not tested here until the host provides CloneV3.

```bash
eg compute local tests/gitclone
eg compute upload tests/gitclone
```
